Three candidate per-mode 'charge magnitudes' on (n1,n2,n3) plane waves:

  Cand I  — per-direction 1-cycle integrals:
           |Q_i|^2 ∝ (n_i/L_i)^2  — picks up each direction's winding
           1D-line modes have ONE nonzero Q_i, others zero
           => 1D modes are NOT dark under this rule

  Cand II — per-plane 2-cycle flux of perpendicular derivative:
           |Φ_{ij}|^2 ∝ (n_k/L_k)^2 * (L_i L_j)^2 * δ(n_i=0) * δ(n_j=0)
           Nonzero ONLY for 1D-line modes (along the perp direction)
           => 2D and 3D modes are dark; only 1D 'shines' — opposite of what we want

  Cand III— per-plane circulation/curl-like (bilinear in n_i, n_j):
           |C_{ij}|^2 ∝ (n_i n_j / (L_i L_j))^2
           Nonzero IFF both n_i AND n_j are nonzero
           => 1D modes are dark; 2D-planar and 3D-mixed are charged
           => THIS implements the hypothesis's selection rule

Selection rule verdict (read down each column):

  Cand I  (per-direction 1-cycle):
    1D modes carry charge.  Picture is killed: predicted ghost flood.

  Cand II (per-plane perpendicular flux):
    Only 1D modes carry charge; 2D and 3D are dark.
    Inverted picture; if this is the physical rule, the 2D-planar
    'three generations' would all be dark — equally bad.

  Cand III (per-plane curl/circulation, bilinear in n_i n_j):
    1D-line modes have ΣC_III = 0.  2D and 3D modes are nonzero.
    This is the rule the hypothesis needs.  If this is the correct
    extension of R19 to 3D, then 1D modes ARE dark (no EM coupling
    to S) and the 2D-planar 'three generations' picture works.

WHICH candidate is the physical one is NOT decided here.  It requires
re-running R19's 2D derivation on the 3-torus, identifying which
topological integral measures asymptotic monopole charge.  This is
a finite analytical extension of R19, not implemented here.
