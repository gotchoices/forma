# Chapter 5 — Stability & dimensionality *(outline for review)*

Role: an honest chapter. Chapter 3 bound a particle in the minimal setting; here we
ask whether it survives in 3D — and largely find that it is *owed*. Brief.

## §1 The dimensional obstruction
- **Derrick's theorem:** a real-scalar lump collapses or disperses in ≥2 extended dimensions. **[cite Derrick; D]**
- So 1D binding does not automatically lift; dimensionality is a real constraint.

## §2 What each object is, dimensionally (the honest catalog)
- 1D **breather/kink** — the Chapter 3 objects. The **kink** is topologically protected; the **breather** (winding-0) is only *long-lived* (dynamically, not protected) — same neutral-mass qualifier as Ch 3 §3 / Ch 6 §3. **[C]**
- 2D **Q-ball** — stable, but by its **Noether** charge, which C1 disavowed as the GRID mechanism → a *borrowed* existence-proof only, not the adopted object. **[C, borrowed]**
- **Topological windings** of a single phase — a U(1) winding is a **vortex line** (codim-2); a kink is a **domain wall** (codim-1). Neither is a localized (codim-3) particle. **[forma]**

## §3 The gap: no demonstrated localized-3D particle (charged or neutral)
- Skyrmion/Hopfion protection needs **π₃** target topology a single compact phase does not supply. **[forma]**
- So localized-3D stability is **owed for both charged and neutral** — not shown here. **[O]**

## §4 The resolution paths — a trichotomy, not a trap
- Not a strict binary. Three branches:
  - **(i) single-phase topological** (kink/vortex) — C1-consistent, but a single U(1) target (S¹) has trivial π₂/π₃, so **no localized 3D soliton**. **[O]**
  - **(ii) Noether Q-ball** — localizes in 3D, but its stabilizer is Noether charge, which **reopens C1**. **[borrowed]**
  - **(iii) richer target space** — a field valued on a **sphere** (S²/S³ → skyrmion / Hopfion via π₂/π₃) is **both** 3D-localized **and** topological (C1-consistent). *This is the live hope* — but note a **product of compact phases (a torus, aspherical) does *not* supply it**; a spherical/non-abelian target is extra structure, and obtaining it in GRID is itself open. Deferred to [metric-charge](../metric-charge/). **[O]**
- So the arc is not stuck in a binary — but the branch that would get everything (iii) is a harder, not a free, escape. **[forma]**

## §5 Where 3D localization would come from
- A GRID **sheet** (fixed-size compact structure + windings) plausibly localizes and stabilizes — but that is [metric-charge](../metric-charge/)'s construction, deferred. **[cite metric-charge; O]**
